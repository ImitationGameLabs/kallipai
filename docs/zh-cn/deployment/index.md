本节下每一章都是运行该平台的一种方式，按各自的平台形态写成一步步的指南。

- [NixOS](nixos/index.md)：用随附的 NixOS 模块部署到 NixOS 主机：基础启动、HTTPS 与日常运维。
- [在 Linux 上安装](install.md)：将 tarball 安装到常规 x86_64 发行版：默认按用户安装，可选 systemd 系统级形态。

容器形态（arion compose）同样可用，其指南为仓库内内部文档 `docs/en/deployment/container.md`。
