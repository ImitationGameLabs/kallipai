[环境变量参考](index.md)的一部分；本页覆盖桌面 daemon。

| 变量                                     | 必填        | 默认                                        | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------- | ----------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `KALLIP_DAEMON_RECORD_DIR`               | 否          | `~/.local/state/kallipai/daemon/instances/` | daemon 的注册记录根：每个受管实例一条 `<slug>.json` 记录（实例 id、属主 uid、目标 uid、workspace、用户环境、启动锚点，以及指向实例数据目录的指针）。逐字设置；覆盖 XDG state-home 推导。                                                                                                                                                                                                                                                                                |
| `KALLIP_TAGMA_SLUG`                      | 是（tagma） | _（无）_                                    | 命名实例；tagma 从它推导数据根（`<data home>/kallipai/tagmata/<slug>`）、配置根与日志，缺失则拒绝启动。slug 语法：`[a-z0-9][a-z0-9-]*`，至多 64 字符。受管实例由 daemon 注入；直跑时自行设置（compose 设 `main`）。                                                                                                                                                                                                                                                     |
| `KALLIP_TAGMA_ACCEPT_UNSAFE_RUN_AS_ROOT` | 否          | 未设                                        | tagma real-root 防护唯一的逃生口。以初始 user namespace 中 euid 0 启动的 tagma（主机真实 root；映射沙箱 root 位于嵌套 namespace，不受影响）拒绝启动。仅精确值 `1` 解锁启动并记一条警告；其他任何值（空、`0`、任意）都保持拒绝。面向无 user namespace 重映射的有根容器；其他场景请用专属无特权用户。                                                                                                                                                                       |
| `KALLIP_HARVEST_BASH`                    | 否          | `/bin/bash`                                 | 登录环境采集所用的 bash（两种启动形态；落下式启动时以目标用户运行）。这是管理常量：没有 `/bin/bash` 的部署（NixOS）把它指向受管 bash；请求或用户环境供给的任何值都动不了它。                                                                                                                                                                                                                                                            |
| `KALLIP_DAEMON_SOCKET_GROUP`             | 否          | _（无）_                                    | 控制 socket 访问组：设置后，daemon 在绑定时把 socket 交给该组（经组数据库解析）并把模式放宽到 0660，组成员即可驱动 daemon。                                                                                                                                                                                                                                                                                                              |
