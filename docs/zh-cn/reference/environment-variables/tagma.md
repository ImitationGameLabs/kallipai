## Agent core

运行时调优参数。全部可选，默认值即合理取值。（身份变量 `KALLIP_ID` / `KALLIP_SUPERVISOR_AGENT_ID` / `KALLIP_ROOT_AGENT_ID` 由 tagma 注入，不在此调优。见[注入 agent shell 会话的变量](agent-shell.md)。）

> **Tagma root agent：** tagma 自持唯一 root agent，启动时主动创建。root 的配置在该时刻从环境读取，尤其是 `KALLIP_WORKSPACE_ROOT`、`KALLIP_MAX_TOOL_ROUNDS` 与 `KALLIP_ROOT_AGENT_PERMISSION_CLASS`（见下）。客户端经 `GET /agents/root` 获取；从不创建它。

| 变量                                           | 默认                                  | 约束                                                   | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------- | ------------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `KALLIP_SYSTEM_PROMPT`                         | 内置提示词                            | _（无）_                                               | 覆盖系统提示词的**静态基底**（姿态 + 工具/轮次模型部分；见 `config.rs` 的 `DEFAULT_SYSTEM_PROMPT`）。逐 agent 的 `# Your identity` 段永远由 tagma 注入在该基底头部，不经环境配置。必须在 tagma 生命周期内保持恒定：root 与所有 subagent 以同一方式解析该变量，字节一致的静态尾部正是提示词前缀缓存跨 agent 生效的前提。                                                                                                                                                                                                      |
| `KALLIP_MAX_TOOL_ROUNDS`                       | _（无上限）_                          | > 0                                                    | 每 agent 最大工具调用轮数。默认无上限。tagma 级 Token 预算是主要安全网。设它可强制一个独立于 Token 消耗的硬轮数上限（例如测试或成本控制）。注意：它**不**约束心跳轮数（裸 assistant 响应重新循环、不在此计数）；见 `KALLIP_MAX_HEARTBEAT_ROUNDS`。                                                                                                                                                                                                                                                                              |
| `KALLIP_MAX_HEARTBEAT_ROUNDS`                  | `3`                                   | > 0                                                    | harness 强制 agent idle 前的最大连续心跳轮数（裸 assistant 重循环）。agent 只有调用 `break` 才停泊；不带工具调用的裸响应不结束运行：harness 注入心跳提示并继续。这道护栏为“自我独白”的 Token 消耗封顶。                                                                                                                                                                                                                                                  |
| `KALLIP_MAX_TRANSIENT_RETRIES`                 | `3`                                   | > 0                                                    | 暂时（故障转移链耗尽）停泊可挣得定时重试的最大连续次数，超过即硬停泊并上报 operator。另受重试策略 `retry_timeout` 钟表时限约束（默认 300s，`KALLIP_RETRY_TIMEOUT_SECS`）。                                                                                                                                                                                                                                                                                |
| `KALLIP_POLIS_URL`                             | _（未设）_                            | HTTPS origin                                           | 平台边缘 origin（`https://api.kallipai.com` 或部署的 `api.<domain>`），一切公开服务调用由它推导：中继连接器对 `{origin}/v1/archeion` 登记，隧道与 envelope POST 限定在 `{origin}/v1/lesche`。设置即激活中继。登记失败（边缘不可达）时 tagma 降级为纯本地：记一条错误、继续服务本地 agent，lesche 消息路由返回 503。`kallip file` CLI 为文件调用读同一变量，未设即报错，没有默认。设了登记码而无此变量，或中继开启但既无存储令牌也无码，都大声启动失败而非降级：凭据绝不发给一个臆测的部署。未设 = 纯本地，无中继。 |
| `KALLIP_TAGMA_RELAY_ENROLLMENT_CODE`           | _（未设）_                            | `sk-enroll-...`                                        | 经 archeion 面板生成的一次性登记码（用户注册之后）。设了 `KALLIP_POLIS_URL` 时 tagma 首次启动必填；登记 origin 与 tagma 令牌一并记录在实例数据根的 `credentials/` 下，令牌存好后码即可移除。已存凭据仍留着码：同一边缘容忍（大声警告并忽略），不同边缘则启动失败并点名两个地址。kallip-daemon 的 start 路径会把已用掉的码从重放环境里滤除，并从 daemon 注册记录中擦除。                          |
| `KALLIP_TAGMA_RELAY_MESSAGE_BURST_MAX`         | `20`                                  | > 0                                                    | 每突发窗口最大 `kallip lesche send` 投递数。为失控的 agent 消息循环封顶。当前进程全局（单 root agent = 单会话，进程级即会话级）；未来多 root 中继会按 agent/轮划定。                                                                                                                                                                                                                                                                                    |
| `KALLIP_TAGMA_RELAY_MESSAGE_BURST_WINDOW_SECS` | `10`                                  | > 0                                                    | 与 `KALLIP_TAGMA_RELAY_MESSAGE_BURST_MAX` 配对的消息突发窗口时长（秒）。                                                                                                                                                                                                                                                                                                                |
| `KALLIP_TAGMA_RELAY_HISTORY_TTL_DAYS`          | `30`                                  | > 0                                                    | 聊天历史保留天数。超龄行被 GC。这是**正常**保留边界：重连设备能重新拉回的范围。离线超过窗口的设备只能看到剩余部分。                                                                                                                                                                                                                                                                        |
| `KALLIP_TAGMA_RELAY_HISTORY_CAP`               | `100000`                              | > 0                                                    | 聊天历史行上限。超出时最老的行被裁掉，不看年龄。**不是用量配额**：防失控兜底（有 bug 的 agent 刷屏、攻击）；TTL 窗口内的正常使用到不了它，裁剪时发一条 `warn!`。                                                                                                                                                                                                                        |
| `KALLIP_WORKSPACE_ROOT`                        | 当前目录                              | _（无）_                                               | agent workspace 的根目录。tagma 启动时读取以配置单例 root agent；subagent 从 supervisor 推导 workspace（`POST /agents` 的 `workspace_root`，须在 supervisor 的 workspace 之内）。                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `KALLIP_CONTEXT_WINDOW_TOKENS`                 | `128000`                              | > 0                                                    | 隐式 env profile（无 [profiles 配置](../../configuration/tagma/methods.md)）的上下文窗口 Token 数；它成为该 profile 的 `max_context_window`。有配置文件时，每个 profile 自行声明 `max_context_window`。                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `KALLIP_OUTPUT_RESERVE_TOKENS`                 | `8192`                                | < `KALLIP_CONTEXT_WINDOW_TOKENS`                              | 上下文窗口内为模型输出保留的 Token 数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `KALLIP_SUMMARY_MAX_TOKENS`                    | `1200`                                | > 0，≤ 固定条目预算                                        | 压缩（摘要）上下文的最大 Token 数。必须放得进固定条目预算（有效预算 × 固定条目比例）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `KALLIP_TOOL_TIMEOUT_SECS`                     | `120`                                 | _（无）_                                               | 单次工具执行的超时（秒）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `KALLIP_PINNED_BUDGET_RATIO`                   | `0.25`                                | 0.0–1.0（开区间）                                      | 分配给固定上下文条目的有效预算份额。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `KALLIP_CONTEXT_THRESHOLDS`                    | `50,60,70,80`                         | 逗号分隔 `1`–`99`，升序，≥ 2 个值                      | 上下文用量阈值（百分比）。最后一个触发自动压缩；之前的作警告。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `KALLIP_MAX_RETRIES`                           | `10`                                  | ≤ 1000                                                 | LLM API 调用的最大重试次数。上限守护尝试预算算术（`u32::MAX` 会回绕成零次尝试）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `KALLIP_RETRY_BASE_DELAY_SECS`                 | `1`                                   | > 0，≤ 3600                                            | 指数重试退避的基础延迟（秒）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `KALLIP_RETRY_MAX_DELAY_SECS`                  | `60`                                  | > 0，≤ 3600                                            | 单次重试退避的上限（秒）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `KALLIP_RETRY_TIMEOUT_SECS`                    | `300`                                 | > 0，≤ 86400                                           | 一次重试序列的总时限（秒）。上限避免期限上的 `Instant + Duration` 溢出。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `KALLIP_POLICY_PRESET`                         | _（未设，默认 `default`）_            | `default`、`auto` 或 `allow-all`                       | tagma 级 `bash_exec` classify preset，启动时读取一次，tagma 生命周期内不可变。每个 agent（root 与 subagent）都在此 preset 下运行。`default`（未设时同）：编目命令放行，未分类命令询问，内置命令拒绝名单（`sed`、`awk`、`ed`、`ex`）与结构性拒绝（如 `curl \| sh`）一律拒绝。`auto` 是实用的宽松模式：未分类命令也放行，拒绝名单与结构性拒绝仍然拒绝。`allow-all` 是**调试 preset，非生产用**：分类器短路放行一切可解析命令，拒绝名单与结构性拒绝不生效。逐命令覆盖经 `ExecPolicy` 另行配置（`PUT /agents/{id}/exec-policy`）。 |

| `KALLIP_TOKEN_BUDGET_WARNINGS`                 | `80,95`                               | 逗号分隔 `1`–`99`，升序，≥ 1 个值                      | 触发 agent 警告消息的 Token 预算用量阈值（百分比）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

### Tagma

这些变量控制 tagma 服务端。

| 变量                        | 必填 | 默认                       | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------------------------- | ---- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `KALLIP_TAGMA_ADDR`         | 否   | `127.0.0.1:3000`           | tagma HTTP 服务端监听地址。容器部署设 `0.0.0.0:3000`。受管实例从 daemon 收到 `127.0.0.1:0`，除非 spawn/start 请求、采集环境或持久化记录重放钉死了该键（组合期跨通道 `SocketAddr` 形状检查；钉死端口被占表现为 spawn 超时回滚或 start 失败并指向日志）。以 `:0` 结尾的钉死值每次启动重绑新动态端口。                                                                                                  |
| `KALLIP_ADVERTISE_URL`      | 否   | `http://127.0.0.1:3000`    | agent 访问本 tagma 所用的 URL。以 `KALLIP_TAGMA_URL` 注入 shell 会话。                                                                                                                                                                                                                                                                                                                                                                           |
| `KALLIP_TAGMA_LOG_TO_STDERR` | 否  | _（未设）_                 | 日志语义：`1`/`true`（大小写不敏感）开启终端（stderr）写入器；未设、为空或任何其他值保持文件默认。                                                                                                                                                                                                                                                                            |
| `KALLIP_PROMPT_QUEUE_SIZE`  | 否   | `5`                        | 每 agent 最大排队消息数（消息通道容量）。满时 `send_message` 返回 503。                                                                                                                                                                                                                                                                                                                                                                         |
| `KALLIP_MAX_AGENTS`         | 否   | `50`                       | 最大并发 agent 实例。范围：1..=1000。满员时创建返回 503。恢复始终豁免。                                                                                                                                                                                                                                                                                                                                                                         |
| `KALLIP_MAX_SUBAGENTS`      | 否   | `20`                       | 每 agent 最大直接 subagent。范围：1..=100。supervisor 满员时创建返回 503。                                                                                                                                                                                                                                                                                                                                                                      |
| `KALLIP_MAX_BODY_SIZE_KB`   | 否   | `1024`                     | HTTP 请求体上限（千字节）。`0` = axum 默认（2 MB）。超限请求返回 413。                                                                                                                                                                                                                                                                                                                                                                          |
| `KALLIP_TOKEN_BUDGET`       | 否   | _（无上限）_               | tagma 级 Token 消耗上限的启动值（见 `docs/en/reference/tagma-api.md` 的 Token Budget 一节）。接受不带后缀的 Token 数或 `K`/`M`/`G` 后缀（如 `500000`、`5M`、`2G`）。`0` 以暂停态启动 tagma：所有 agent 阻塞，直到经 `POST /budget` 设定有限预算。未设则无上限启动；空值或非法值以解析错误启动失败，而非悄悄无上限启动。运行时预算经 `GET`/`POST /budget` 读取与更改，不经本变量。                                  |
| `KALLIP_OPERATOR_TOKEN`     | 否   | _（随机 `sk-operator-…`）_ | 预设 tagma operator 令牌。未设时生成随机 256 位 `sk-operator-…` 令牌并打印到 stdout。tagma 只保留其哈希。自动化场景令牌需预先已知时设置；不可为空。                                                                                                                                                                                                                                                                                         |
| `KALLIP_LLM_API_USER_AGENT` | 否   | `kallip/<tagma-version>`   | 出站 LLM chat completion 请求携带的 User-Agent 头。逐字覆盖（保留首尾空白）；非法头字符（如换行）快速失败（活跃 set 在启动时，故障转移在首次失败时惰性触发）。                                                                                                                                                                                                                                                                                   |

### LLM Provider

这些变量选择并配置 LLM 后端。没有[模型配置方法](../../configuration/tagma/methods.md) 配置文件时为**必填**。

环境变量路径只支持 `deepseek` 与 `openai-compatible`；`openai-responses` 与 `anthropic` 族要经[模型配置方法](../../configuration/tagma/methods.md) 配置文件使用。

| 变量                                | 必填        | 默认             | 说明                                                                                                        |
| ----------------------------------- | ----------- | ---------------- | ----------------------------------------------------------------------------------------------------------- |
| `KALLIP_LLM_PROVIDER`               | **是**      | _（无）_         | LLM 后端。支持取值：`deepseek`、`openai-compatible`。                                                       |
| `KALLIP_LLM_MODEL`                  | **是**      | _（无）_         | 传给 provider 的模型标识（如 `deepseek-v4-flash`、`glm-5.1`）。                                             |
| `KALLIP_LLM_DEEPSEEK_API_KEY`       | 视条件      | _（无）_         | DeepSeek provider 的 API 密钥。`KALLIP_LLM_PROVIDER=deepseek` 时必填。                                      |
| `KALLIP_LLM_DEEPSEEK_BASE_URL`      | 否          | DeepSeek 默认    | 覆盖默认 DeepSeek API 端点。                                                                                |
| `KALLIP_LLM_OPENAI_COMPAT_API_KEY`  | 视条件      | _（无）_         | OpenAI 兼容 provider 的 API 密钥。`KALLIP_LLM_PROVIDER=openai-compatible` 时必填。                          |
| `KALLIP_LLM_OPENAI_COMPAT_BASE_URL` | 视条件      | `""`             | 覆盖默认 OpenAI 兼容 API 端点。`KALLIP_LLM_PROVIDER=openai-compatible` 时必填。                             |
