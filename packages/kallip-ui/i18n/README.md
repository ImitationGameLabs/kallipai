# kallip-ui i18n

Shared inlang project (en base, zh). `messages/*.json` are the tracked source
of truth; compiled output lives in `../src/paraglide` (gitignored) and is
regenerated by the vite plugin in each app, or manually via `npm run i18n`
(repo root).

> **Version pin**: `@inlang/paraglide-js` is pinned to `2.20.0` (see
> `packages/kallip-web/package.json`). On `2.24.x` the compile silently
> produced **zero** messages while still reporting success. Root cause not
> identified — diffing the sdk's path-helpers between the two versions showed
> no explanatory change. After any bump, verify the message count in
> `src/paraglide/messages/_index.js` before removing this note.

## Fresh-clone bootstrap

`src/paraglide` is compiled output and not in git. After installing
dependencies, run `npm run sync` once (repo root): the kallip-web `prepare`
script compiles paraglide into `src/paraglide`. Without this step
`deno task check` fails on the missing `../paraglide` imports.
