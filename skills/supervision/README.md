# Supervision skills

Skills for auditing agent work practices against the skill library and
project standards. `supervision/self-reporting` defines how the root
agent reports at checkpoints; `supervision/practice-audit` defines how
a dedicated auditor subagent checks for behavioral drift and produces
advisory feedback.
