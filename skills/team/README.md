# Team skills

How to structure, staff, and sustain multi-agent teams. The principles
(`what-makes-a-good-team`) apply across domains; each domain template
(e.g. `software-development`) turns those principles into concrete roles,
pipeline, and scaling rules. For the spawn/message/cleanup mechanics, see
`agent/subagent-management`.
