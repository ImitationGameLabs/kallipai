# Research skills

Skills for systematic, multi-source investigation. The entry point is
`research/deep-research` — it classifies the question and routes to the
right domain flow. Domain flows (`research/academic`,
`research/open-source`) carry the source-specific steps. Source skills
(`research/arxiv-reading`, `research/web-search`) provide the low-level
with individual sources.
